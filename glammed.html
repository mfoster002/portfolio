Glammed

Project Overview

Glammed is a tailored beauty tutorial experience designed to help users
create personalized beauty routines. The app features a user-friendly
interface, step-by-step tutorials, and customization options to suit
individual preferences.

Key Features

  • Personalized beauty tutorials
  • Customizable routines
  • Step-by-step guidance

User Persona

Understanding the Problem

Many users struggle to find beauty tutorials that match their unique
preferences and needs. Glammed aims to solve this by providing a
personalized experience that adapts to individual styles and goals.

Key Takeaways

  • Users value tutorials tailored to their specific needs.
  • Clear, step-by-step instructions improve user satisfaction.

Wireframes

These wireframes were created to outline the app's layout and functionality.

I focused on creating a clean, user-friendly interface that prioritized ease of use.

User Testing

After conducting user testing, I received valuable feedback that helped refine the design.

Users appreciated the personalized approach but suggested improving the navigation flow.

Final Design

The final design incorporates user feedback and focuses on a clean, modern aesthetic.

It features a color palette that is both calming and engaging, with clear typography for easy readability.
