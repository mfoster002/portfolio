Glammed

Project Overview

Glammed is a platform for users to complete beauty profiles and receive personalized
product and tutorial recommendations based on physical traits, trends, and preferences.

Timeline: May – July 2024
My Role: UX Designer
Tasks: User research, wireframing, prototyping

Problem & Goal

Problem: Users struggle to find tutorials and products that match their unique features.

Goal: Offer tailored product/tutorial recommendations using personalized beauty profiles.

User Research & Insights

Methods: Competitive audits, personas, empathy & journey maps

Main Pain Points:

  • Overwhelming amount of info without guidance
  • Tutorials not matching learning styles
  • Generic tutorials not tailored to individual features
  • Lack of gender inclusivity

Wireframes

These wireframes emphasized clear navigation, multiple sign-up options, and engaging visuals.

Tutorial designs included both video and text tutorials for accessibility, with expandable menus and side navigation for ease of use.

User Testing

Insights from Unmoderated Studies:
- Menu was too high
- Users wanted to upload or take photos
- Quiz navigation (buttons, question size) was confusing

Insights from Moderated Studies:
- Needed better button differentiation
- Users wanted more flexible navigation and allergy considerations
- Identified a checkout dead-end

Final Design

The final design incorporates user feedback and focuses on a clean, modern aesthetic.
It features a color palette that is both calming and engaging, with clear typography for easy readability.

Refinements:
- More photo upload options
- Square buttons for multi-select options
- Improved color contrast (4.5:1)
- Icons next to text for accessibility
- Video with captions + written tutorials
